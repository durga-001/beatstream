# 🎵 BeatStream

🔗 **Live Link:** [beatstream.com](https://beatstream-xqga.onrender.com/)

BeatStream is a Spotify-inspired music streaming web app built with React and Vite. It features a clean, responsive UI styled with Tailwind CSS and client-side routing powered by React Router. Users can browse tracks, playlists, and enjoy a smooth, modern listening experience right in the browser.
